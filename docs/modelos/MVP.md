## Critérios de validação

O MVP será considerado válido quando:

- [ ] o fluxo principal puder ser demonstrado;
- [ ] os requisitos essenciais forem atendidos;
- [ ] o resultado puder ser validado por outra pessoa;
- [ ] limitações conhecidas estiverem registradas.
