# Uso de IA

IA foi utilizada como ferramenta de apoio durante o desenvolvimento, principalmente em planejamento, discussão de arquitetura, investigação, revisão e geração assistida de trechos. A equipe definiu as regras, direcionou a implementação, revisou as alterações e executou os testes. O processo não consistiu em gerar o sistema inteiro com IA para somente validá-lo ao final.
